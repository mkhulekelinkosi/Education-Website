# LearnigGuide - Personalized Learning Platform

A modern website that helps students discover their learning style and master Mathematics, Physical Sciences, and English with personalized guidance.

## Overview

LearnigGuide allows students to:
1. **Take a Learning Style Assessment** - Identify whether they're Visual, Auditory, or Kinesthetic learners
2. **Get Personalized Video Recommendations** - Watch curated videos based on their learning style
3. **Explore Subject Guides** - Access tailored study approaches for Math, Sciences, and English
4. **Practice with Questions** - Test knowledge with subject-specific practice questions

## Design

- **Color Scheme**: Dark blue (#0a1428) with gold (#d4af37) accents - luxury and professional
- **Style**: Clean, modern, responsive layout
- **Interactive Elements**: Learning style quiz with instant results

## Files

- `index.html` – Main landing page with quiz and subject sections
- `styles.css` – Dark theme styling with gold and blue accents
- `script.js` – Quiz logic and interactive features
- `README.md` – Project documentation

## Run Locally

```bash
python -m http.server 8000
```

Visit: `http://localhost:8000`

## Deploy on GitHub Pages

1. Make repository public
2. Go to Settings → Pages
3. Select `main` branch, `/` folder
4. Your site will be live at: `https://mkhulekelinkosi.github.io/Education-Website/`
