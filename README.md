# Copilot Starter Website

A simple, beginner-friendly website that introduces GitHub Copilot and explains how to get started building a website or app with AI-powered code assistance.

## Files
- `index.html` – main landing page
- `styles.css` – styling and layout
- `script.js` – mobile menu behavior and footer year

## Run locally
Open `index.html` in a browser, or serve the folder with a local server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Purpose
This project is designed to help users understand:
- what GitHub Copilot is
- how to begin using it
- the best practices for prompting and reviewing AI-generated code
- how to build a simple website faster
